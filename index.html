JavaScript funkcijas projekta darbam

Izmēģini HTML, CSS un JavaScript paraugus un pielāgo izvēlēto funkciju vajadzībai, ko noskaidroji lomu spēles intervijā.

Sasniedzamais rezultāts

Tekstuālā programmēšanas valodā raksta un pārbauda funkcijas konkrēto lietotāja vajadzību apmierināšanai. (T.9.2.6.1., T.9.2.6.2.)

Funkciju paraugi

Teorija un notikumi Mainīt skaitu Aprēķināt cenu Atzīmēt statusu Saglabāt vērtību ar laika zīmogu Atlasīt ierakstus Kārtot pēc termiņa Mainīt izskatu Atvērt papildu informāciju

Darbs ar paraugu

  1. Vienā teikumā pieraksti, ko lietotājs vēlas izdarīt un ko viņš vēlas pēc tam redzēt.
  2. Sāc ar sadaļu “Teorija un notikumi”, tad katrā paraugā izmēģini pamata kodu un salīdzini ar pilno variantu.
  3. Izmēģini atbilstošu paraugu. Saglabā tā kodu kā HTML failu, atver to pārlūkā un pielāgo datus, tekstus un noteikumus savai situācijai.
  4. Pieraksti pārbaudes darbību, gaidīto un faktisko rezultātu. Ja tie atšķiras, izlabo kodu un pārbaudi vēlreiz.

Notikumi mājas lapā

Notikums ir darbība vai brīdis, uz kuru pārlūks var reaģēt, izsaucot funkciju.

Notikumu piemēri

  • Lietotājs noklikšķina uz HTML pogas.
  • Tīmekļa lapa ir pabeigusi ielādi.
  • Lietotājs uzved peles kursoru uz elementa.
  • Lietotājs nospiež tastatūras taustiņu.
  • Mainās HTML ievades lauka vērtība.

onclick="apstiprini()" sasaista notikumu ar funkcijas izsaukumu. Funkciju apraksta JavaScript daļā ar function apstiprini() { … }.

oninput reaģē uz katru ievades izmaiņu. onchange teksta laukā parasti notiek pēc vērtības maiņas un iziešanas no lauka, bet izvēlnē — pēc izvēles maiņas.

Izveides gaita. Izveido pogu un rezultāta lauku. Mainīgajam piešķir 0. Funkcijā pieskaiti 1 un parādi vērtību.

Salīdzini ar pilno paraugu zemāk un izvēlies savai vajadzībai piemērotās darbības.

Izmēģini

Lapas elementi

Divas pogas un rezultāta elements <output>.

Funkcijas darbība

Katra poga izsauc vienu funkciju ar citu argumentu. Funkcija pieskaita izmaiņu un saglabā skaitu vismaz 0.

Izveides gaita

  1. Izveido pogas un rezultāta lauku.
  2. Mainīgajā saglabā sākuma vērtību 0.
  3. Uzraksti funkciju ar parametru un izsauc to ar 1 vai −1.

Kā pārbaudīt

  1. Nospied + divreiz → 2.
  2. Nospied − trīsreiz → 0.

Pielāgo savai lomai. Pasūtījuma daudzumam maini pogu aprakstus. Punktu skaitīšanai pievieno pogu ar citu argumentu.

Aprēķināt cenu

Lietotājs vēlas uzreiz redzēt kopējo cenu pēc daudzuma vai varianta maiņas.

Pamata piemērs

Ievadīto daudzumu reizina ar cenu 5 €.

Lapas elementi. Daudzuma ievades lauks un rezultāta lauks.

Izveides gaita. Izveido skaitļa lauku. Ar oninput izsauc funkciju. Pārbaudi lauku un reizini daudzumu ar 5.

Pārbaude. Ievadi 3 → 15 €; 0 → 0 €; iztukšo lauku → norāde.

Skatīt un iegūt kodu
<!doctype html>
<html lang="lv">
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Vienkāršs piemērs</title>
<style>body { font: 16px system-ui; padding: 12px; } button, input { font: inherit; margin: 4px; } </style>
<body>
<label>Daudzums <input id="daudzums" type="number" min="0" step="1" required value="1" oninput="rekini()"></label><p id="summa">5 €</p>
<script>
function rekini() {
  const lauks = document.getElementById("daudzums");
  const summa = document.getElementById("summa");
  // HTML noteikumi pārbauda, vai ievadīts vesels skaitlis no 0.
  if (lauks.checkValidity()) {
    summa.textContent = Number(lauks.value) * 5 + " €";
  } else {
    summa.textContent = "Ievadi veselu skaitli no 0.";
  }
}
</script>
</body>
</html>

Salīdzini ar pilno paraugu zemāk un izvēlies savai vajadzībai piemērotās darbības.

Izmēģini

Lapas elementi

Skaitļa lauks, izvēlne <select>, abu lauku etiķetes un <output>.

Funkcijas darbība

Funkcija nolasa daudzumu un izvēlētā varianta cenu. Derīgas ievades gadījumā tā reizina abas vērtības un parāda summu.

Izveides gaita

  1. Izvēlnes variantu value atribūtos ieraksti cenas.
  2. Piesaisti aprēķinu ievades notikumam input un izvēlnes notikumam change.
  3. Pārbaudi lauku un parādi summu vai paziņojumu.

Kā pārbaudīt

  1. Ievadi 3 un izvēlies variantu par 8 € → 24.00 €.
  2. Ievadi 0 → 0.00 €.
  3. Iztukšo lauku vai ievadi −1 → paziņojums.

Pielāgo savai lomai. Diviem preču veidiem izmanto divus daudzuma laukus un saskaiti abu veidu starpsummas.

Pilnā parauga HTML, CSS un JavaScript kods 
<!doctype html>
<html lang="lv">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Aprēķināt cenu</title>
<style>
body { font: 16px/1.5 system-ui, sans-serif; color: #20223b; margin: 16px; }
button, input, select { font: inherit; padding: .35em .65em; }
button { cursor: pointer; }
label { display: block; margin: .3em 0; }
output { padding: 0 .35em; font-weight: bold; }

</style>
</head>
<body>
<label>Daudzums
  <input id="daudzums" type="number" min="0" step="1" required
         value="1" oninput="aprekini()">
</label>
<label>Variants
  <select id="cena" onchange="aprekini()">
    <option value="5">Pamata (5 €)</option>
    <option value="8">Papildināts (8 €)</option>
  </select>
</label>
<p>Kopā <output id="summa" aria-live="polite">5.00 €</output></p>
<script>
function aprekini() {
  const lauks = document.getElementById("daudzums");
  const summa = document.getElementById("summa");

  // min, step un required nosaka atļauto ievadi.
  if (!lauks.validity.valid) {
    summa.textContent = "Ievadi veselu skaitli no 0.";
    return;
  }

  const cena = Number(document.getElementById("cena").value);
  summa.textContent = (lauks.valueAsNumber * cena).toFixed(2) + " €";
}
</script>
</body>
</html>

Salīdzini ar pilno paraugu zemāk un izvēlies savai vajadzībai piemērotās darbības.

Izmēģini

Lapas elementi

Atzīmējamas rūtiņas ar etiķetēm, rezultāta elements un CSS klase izcēlumam.

Funkcijas darbība

Funkcija nolasa rūtiņu stāvokli, saskaita atzīmētās un piešķir izpildītajiem ierakstiem CSS klasi.

Izveides gaita

  1. Izveido rūtiņas ar kopīgu klasi.
  2. Ar checked nosaki, kura rūtiņa ir atzīmēta.
  3. Atjauno kopsavilkumu un rindas klasi katrā change notikumā.

Kā pārbaudīt

  1. Atzīmē vienu rūtiņu → 1 no 3 un rindas izcēlums.
  2. Noņem atzīmi → 0 no 3 un izcēlums pazūd.
  3. Atzīmē visas → 3 no 3.

Pielāgo savai lomai. Zināmu atzīmi var izmantot mantu sarakstam, darba daļām vai paziņojumiem. Ja vajag trīs statusus, izmanto izvēlni.

Pilnā parauga HTML, CSS un JavaScript kods 
<!doctype html>
<html lang="lv">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Atzīmēt statusu</title>
<style>
body { font: 16px/1.5 system-ui, sans-serif; color: #20223b; margin: 16px; }
button, input, select { font: inherit; padding: .35em .65em; }
button { cursor: pointer; }
label { display: block; margin: .3em 0; }
output { padding: 0 .35em; font-weight: bold; }
.pabeigts { color: #176247; font-weight: bold; }
</style>
</head>
<body>
<label><input class="darbs" type="checkbox" onchange="atjauno()"> Sagatavot materiālus</label>
<label><input class="darbs" type="checkbox" onchange="atjauno()"> Pārbaudīt saturu</label>
<label><input class="darbs" type="checkbox" onchange="atjauno()"> Iesniegt darbu</label>
<p>Paveikts <output id="paveikts" aria-live="polite">0 no 3</output></p>
<script>
function atjauno() {
  const darbi = document.querySelectorAll(".darbs");
  let skaits = 0;

  for (const darbs of darbi) {
    if (darbs.checked) {
      skaits += 1;
    }
    // Klase ir uz etiķetes tik ilgi, kamēr rūtiņa ir atzīmēta.
    darbs.parentElement.classList.toggle("pabeigts", darbs.checked);
  }

  document.getElementById("paveikts").textContent =
    skaits + " no " + darbi.length;
}
</script>
</body>
</html>

Atlasīt ierakstus

Lietotājs vēlas garā sarakstā ātri atrast piemērotus ierakstus.

Pamata piemērs

Rāda rindas, kuru tekstā ir meklētie burti.

Lapas elementi. Meklēšanas lauks un trīs saraksta rindas.

Izveides gaita. Izveido sarakstu. Nolasi ievadi. Ciklā pārbaudi katras rindas tekstu un maini hidden.

Pārbaude. Ievadi zāl → divas rindas; xyz → neviena; notīri → visas.

Skatīt un iegūt kodu
<!doctype html>

function mekle(teksts) {
  const rindas = document.querySelectorAll("#saraksts li");
  // Salīdzina mazos burtus, lai Z un z meklēšanā sakristu.
  teksts = teksts.toLowerCase();
  for (const rinda of rindas) {
    rinda.hidden = !rinda.textContent.toLowerCase().includes(teksts);
  }
}

</body>
</html>

Izmēģini

Lapas elementi

Meklēšanas lauks, kategorijas izvēlne, saraksts un rezultātu ziņojums.

Funkcijas darbība

Funkcija salīdzina katra ieraksta tekstu un kategoriju ar izvēlētajiem kritērijiem. Rāda tikai ierakstus, kas atbilst abiem kritērijiem.

Izveides gaita

  1. Katram ierakstam pievieno data-veids atribūtu.
  2. Nolasi meklējamo tekstu un izvēlēto kategoriju.
  3. Izmanto hidden, lai paslēptu neatbilstošās rindas, un saskaiti redzamās.

Kā pārbaudīt

  1. Ieraksti “zāl” → 2 ieraksti.
  2. Atstāj “zāl” un izvēlies “Ārā” → 0.
  3. Notīri lauku un izvēlies “Visi” → 3.

Pielāgo savai lomai. Teksta un kategorijas vietā vari salīdzināt pieturu un dienas veidu vai pievienot cenas robežu.

function atlasi() {
  const teksts = document.getElementById("meklet").value.trim().toLowerCase();
  const veids = document.getElementById("veids").value;
  const ieraksti = document.querySelectorAll("#ieraksti li");

    // Abiem nosacījumiem jābūt patiesiem.

Kārtot pēc termiņa

Lietotājs vēlas redzēt, kurš darbs jāveic vispirms.

Pamata piemērs

Sakārto datumu masīvu no agrākā uz vēlāko.

Lapas elementi. Poga un vieta sakārtotajiem datumiem.

Izveides gaita. Izveido masīvu ar datumiem GGGG-MM-DD formātā. Izmanto sort un parādi rezultātu.

Pārbaude. Nospied → 2027-03-12, 2027-03-19, 2027-04-02. Atkārto → tā pati secība.

Skatīt un iegūt kodu

  const datumi = ["2027-04-02", "2027-03-12", "2027-03-19"];
  // Šādā formātā teksta secība sakrīt ar datumu secību.
  datumi.sort();

Salīdzini ar pilno paraugu zemāk un izvēlies savai vajadzībai piemērotās darbības.

Izmēģini

Lapas elementi

Poga, saraksts ar datumiem un īss paziņojums pēc kārtošanas.

Funkcijas darbība

Funkcija pārvērš saraksta rindas masīvā, salīdzina datumus un saliek esošās rindas jaunā secībā.

Izveides gaita

  1. Datumu katrai rindai ieraksti formātā GGGG-MM-DD.
  2. Ar sort sakārto rindas, salīdzinot datumu virknes.
  3. Ar append pārvieto esošās rindas sakārtotajā secībā.

Kā pārbaudīt

  1. Nospied pogu → 12.03., 19.03., 02.04.
  2. Nospied vēlreiz → secība saglabājas un ir tās pašas trīs rindas.

Pielāgo savai lomai. Rindām pievieno priekšmetu, nosaukumu vai atbildīgo. Viena datuma ieraksti saglabās savstarpējo sākotnējo secību.

function sakarto() {
  const saraksts = document.getElementById("termini");
  const rindas = Array.from(saraksts.children);
