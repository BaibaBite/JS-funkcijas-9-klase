# JavaScript funkcijas projekta darbam

Interaktīvs mācību materiāls 9. klases datorikai.

## Atvērt datorā

Atver `index.html` pārlūkā. Visa lapa un demonstrācijas ir vienā failā. Internetu izmanto ārējo mācību resursu atvēršanai.

## Publicēt GitHub Pages

1. Izveido GitHub repozitoriju un augšupielādē `index.html` tā saknē.
2. Atver **Settings → Pages**. Sadaļā **Build and deployment** izvēlies **Deploy from a branch**.
3. Izvēlies zaru ar failu (parasti `main`) un mapi **/(root)**. Nospied **Save**.
4. Kad publicēšana pabeigta, **Settings → Pages** atver vietnes adresi.

[GitHub dokumentācija par publicēšanas avotu](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Papildinātā versija

Pievienota notikumu teorija, septiņas notikumu demonstrācijas un kopīgs notikumu secības piemērs. Katram no astoņiem funkciju paraugiem ir vienkāršs pamata variants un pilnais variants. Katru kodu var kopēt vai lejupielādēt kā patstāvīgu HTML failu. Pēc pārlādes paraugu dati atgriežas sākumstāvoklī.
